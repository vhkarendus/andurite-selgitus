Mis on fototransistor?

Fototransistor näeb välja nagu läbipaistev LED, aga töötab vastupidi: LED teeb valgust, fototransistor reageerib valgusele. Tal on kaks jalga: pikk jalg on kollektor (+) ja lühike jalg on emitter (−).

Tavalisel transistoril avab voolu kolmas jalg ehk baas. Fototransistoril baasi jalga pole – tema „baasiks“ on valgus. Mida rohkem valgust langeb kristallile, seda suurem vool läbib fototransistori kollektorist emitterisse. Pimedas läbib teda vaid tühine pimevool.

Oluline: fototransistor ei muuda oma takistust nagu potentsiomeeter või fototakisti (LDR). Valgus muudab voolu. Seda tuleb meeles pidada, kui valime takistit. Liiguta valguse liugurit ja vaata, kuidas vool muutub.

Miks on takisti vaja?

Arduino mõõdab pinget, mitte voolu

analogRead(A0) mõõdab pinget pinil A0 (0–5 V → 0–1023). Fototransistor annab aga voolu. Seega on vaja midagi, mis teisendab voolu pingeks. Selleks sobib kõige lihtsam komponent – takisti. Ohmi seaduse järgi tekib takistil pinge:

UA0 = I · R

Takisti ühendatakse emitteri ja GND vahele. Teda nimetatakse allatõmbetakistiks (ingl. pull-down), sest pimedas, kui voolu peaaegu pole, tõmbab ta pini A0 pinge alla 0 V juurde. Ilma temata on pin A0 „hõljuv“: ta pole ühendatud ei 5 V ega GND-ga ja näit hüppab juhuslikult – sõltudes isegi sellest, kas sa puudutad juhet.

Lülita takisti välja ja vaata, mis juhtub Serial Monitoris.

// Fototransistor: kollektor (pikk jalg) → 5V
// emitter (lühike jalg) → A0 ja 10 kΩ → GND
const int ANDUR_PIN = A0;
const float R = 10000.0; // takisti oomides

void setup() {
  Serial.begin(9600);
}

void loop() {
  int lugem = analogRead(ANDUR_PIN);
  float pinge = lugem * (5.0 / 1023.0);
  float vool_uA = pinge / R * 1000000.0;

  Serial.print("analogRead: ");
  Serial.print(lugem);
  Serial.print("  Pinge: ");
  Serial.print(pinge, 2);
  Serial.print(" V  Vool: ");
  Serial.print(vool_uA, 0);
  Serial.println(" uA");
  delay(500);
}

          

        

      

    

    


    
    
Takisti suurus = tundlikkus

    

      
Suur takisti – tundlik, väike takisti – talub eredat valgust

      

        Valemist U = I · R järeldub: sama valguse (sama voolu) juures annab
        suurem takisti suurema pinge. Suure takistiga andur „näeb“ juba nõrka valgust – ta on
        tundlikum.
      

      

        Aga pinge ei saa kasvada lõpmatuseni. Toide on 5 V ja fototransistori enda peale jääb vähemalt
        umbes 0,3 V. Seega ei tõuse pinge A0-l üle ≈ 4,7 V (analogRead ≈ 960, mitte 1023!).
        Kui see piir on käes, ütleme, et fototransistor on küllastunud: valgust võib lisanduda,
        aga näit enam ei muutu. Andur on „pimestatud“.
      

      

        Kasulik vahemik (graafikul sinine ala) näitab, millise valguse juures see takisti
        valgustugevusi eristab. Vali eri takisteid ja vaata, kuidas vahemik nihkub.

Fototransistor päriselus

    

      
Kuidas eristada kollektorit ja emitterit?

      

        Pikk jalg = kollektor (+), ühenda 5 V-ga. Lühike jalg = emitter (−), ühenda
        A0 ja takistiga. Kui jalad on juba lühikeseks lõigatud, proovi lihtsalt: ühenda ja kata andur käega.
        Kui näit valgusega ei muutu ja jääb nulli lähedale, pööra fototransistor ümber. Takisti piirab voolu,
        nii et lühikese proovimisega ei lähe midagi katki.
      

      

        Fototransistor on väga sarnane LED-iga. Kui komplektis on mõlemad, hoia neid eraldi karpides!

Teine näide: termistor

    

      
Sama küsimus, teine andur

      

        Termistor kuulub teise andurite perre: temperatuur muudab tema takistust, mitte voolu.
        Kasutame NTC termistorit (sama mis telemeetria tutorialis 03): 25 °C juures 10 kΩ,
        B-väärtus 3950 K. NTC tähendab, et soojemaks minnes takistus väheneb.
      

      

        Takistuse muutusest pinge saamiseks ühendame termistori ja takisti pingejagurina:
        5V → termistor → A0 → takisti R → GND. Pinge A0-l:
      

      UA0 = 5 V · R / (R + RNTC)
      

        Soojemaks → RNTC väheneb → pinge A0-l kasvab. Küllastust siin pole, sest
        pinge jääb alati 0 ja 5 V vahele. Takisti valik mõjutab aga tundlikkust: mitu
        analogRead-i sammu muutub näit ühe kraadi kohta.
      

      

        Reegel: pingejagur on kõige tundlikum seal, kus R = RNTC.
        Meie termistor on 10 kΩ just 25 °C juures, seega on 10 kΩ takisti parim toatemperatuuri mõõtmiseks.
        Kui pead mõõtma vahemikku Tmin…Tmax, vali
      

      R = √( RNTC(Tmin) · RNTC(Tmax) )
      

        Näide: GreenPoweri mootori temperatuur 20…80 °C. RNTC(20 °C) ≈ 12,5 kΩ,
        RNTC(80 °C) ≈ 1,27 kΩ → R = √(12,5 · 1,27) kΩ ≈ 4,0 kΩ → valime 3,9 kΩ.
        Proovi kalkulaatoriga ja vaata graafikult, kuidas kõver nihkub.

// 5V → termistor → A0 → R → GND
const int TERM_PIN = A0;
const float R_FIXED = 10000.0; // takisti R
const float R0 = 10000.0;      // NTC 25 °C juures
const float T0 = 298.15;       // 25 °C kelvinites
const float B  = 3950.0;       // andmelehelt!

void setup() {
  Serial.begin(9600);
}

void loop() {
  int lugem = analogRead(TERM_PIN);
  if (lugem < 1) lugem = 1; // väldi nulliga jagamist
  float pinge = lugem * (5.0 / 1023.0);
  float r_ntc = R_FIXED * (5.0 / pinge - 1.0);
  float t_k = 1.0 / (1.0 / T0 + log(r_ntc / R0) / B);
  float t_c = t_k - 273.15;

  Serial.print("analogRead: ");
  Serial.print(lugem);
  Serial.print("  R_NTC: ");
  Serial.print(r_ntc, 0);
  Serial.print(" oomi  T: ");
  Serial.print(t_c, 1);
  Serial.println(" C");
  delay(500);
}
